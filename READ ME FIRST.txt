How to upload on github.com
---------------------------
Repo root -> "Add file" -> "Upload files" -> drag in app.py and
theme_css.py -> "Commit changes" -> Commit directly to main.
Uploading a file with the same name replaces it.

Then: tpcafe-app.streamlit.app -> Manage app -> the three dots ->
Reboot app -> hard refresh with Cmd-Shift-R.

What to expect
--------------
Sand/stone surfaces, terracotta primary buttons, Nunito headings,
pill buttons and inputs, rounded cards, round tick-boxes, tighter
density.

Streamlit still owns the page structure, so the task board will not
become the seven side-by-side day cards from the design, and the
sidebar will not become the collapsible rail. Those are layout, not
styling - see HANDOFF.md, route 2.
