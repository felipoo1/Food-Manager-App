FIXES
-----
1. MASTER STOCK LIST WAS BROKEN - raw HTML printed on screen and the
   ingredient names ran one letter per line.

   Cause: the card HTML was written indented inside the Python file.
   Markdown treats any line starting with 4+ spaces as a CODE BLOCK,
   so Streamlit rendered the tags as literal text instead of markup.
   All three HTML blocks (ingredient card, sidebar brand, group
   heading) are now built as flat single-line strings.

2. DAY CARD SHADING now matches the mock. Streamlit paints the card
   background on a child of the border wrapper, not the wrapper
   itself, so the sand fill never applied. Both are now set: day
   cards sand (#eee7db), task cards inside them cream (#f9f4ed) with
   a hairline border.
