WHAT THIS FIXES
---------------
The theme WAS already working - cream page, sand sidebar, terracotta
button. These were the things still making it look wrong:

1. Sidebar nav was centred with big gaps between items.
   Cause: the CSS targeted ".stButton", a class Streamlit 1.63 no
   longer emits. Rewritten against the current data-testid hooks, so
   nav items are now left-aligned, tight, and pill-shaped.

2. The active page was plain orange markdown text, not a pill.
   app.py now renders it as a disabled button, which the CSS paints
   as the solid dark pill from the mock.

3. Recipe placeholder tiles were hardcoded blue / orange / purple
   (#2563EB, #F2722D, #7C3AED) and clashed with the cream. Now sand,
   with a 16px radius.

4. The build stamp line has been removed.
